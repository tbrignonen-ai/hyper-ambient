# SKU10 — script panne / reprise (soutenance, 1 page)

Profil figé le 17 : Luciole-8B (`mother-local` :8090) + host-agent (:8001) + Presence + SearXNG.
Occamy et le gros TTS GPU sont **hors profil** — ne jamais les charger en dépannage.

## Avant de parler (30 s, en coulisse)
1. `docker ps` → `mother-core-dev` doit être `Up`. Sinon `docker start mother-core-dev` (jamais `recreate`).
2. `GET http://localhost:8090/health` → 200.
3. `GET http://localhost:8001/health` (ou équivalent) → 200.
4. Presence visible à l'écran (`pythonw native/presence/app.py` si fermée).
5. `nvidia-smi` : VRAM < ~10 Go. Si un process orphelin traîne (Occamy, ancien hostagent), le tuer avant de commencer.

## Pendant la démo — si ça casse, dans l'ordre

| Symptôme | Cause probable | Reprise |
|---|---|---|
| Presence ne répond plus au PTT | host-agent mort ou bloqué | `docker exec mother-core-dev bash /workspace/dev/scripts/relancer_routeur.sh` — relance propre le host-agent, ~10–15 s, message `host-agent pret` en fin de log |
| Réponse vocale muette ou coupée en boucle | TTS Supertonic planté | Même commande que ci-dessus (relance host-agent = relance MOUTH aussi) ; si ça persiste, annoncer à l'oral et repasser en texte |
| Header `Authorization` illégal / les deux voies tombent | `.env.local` édité sous Windows → CRLF collé à la clé | Ne pas toucher `.env.local` en live ; le script le lit déjà en éliminant le `\r` — un simple relancer_routeur suffit |
| Presence ne voit pas la coupure après une relance host-agent | reconnexion silencieuse (bug connu du 15) | Fermer/rouvrir la fenêtre Presence une fois ; le premier appui après la relance peut être perdu, prévenir avant de démarrer |
| VRAM proche du plafond / lenteur | un autre modèle chargé en double (swap raté) | `nvidia-smi`, identifier le PID en trop, le tuer ; ne jamais lancer Occamy pendant SKU10 |
| Pont Codex/Claude (`:8765`/`:8766`) injoignable | bridge Windows pas démarré ou coffre RO | Ne pas dépanner en live — annoncer que l'escalade outil est indisponible, rester sur le local (`BRAIN_REFLEX_ANSWERS=1`, déjà le défaut) |
| Rien ne repart après une relance | conteneur lui-même à plat | `docker start mother-core-dev` (pas de `down`/`recreate`), attendre `Up`, puis refaire la séquence "avant de parler" au complet |

## Règle d'or pendant la soutenance
Une seule reprise = `relancer_routeur.sh` dans le conteneur. Ne jamais enchaîner plusieurs tentatives différentes à la suite : ça multiplie les process fantômes. Si la première reprise ne suffit pas, annoncer le blocage à l'oral plutôt que de dépanner en direct devant le jury.

## Non-objectifs (ne pas tenter de sauver ça en live)
Occamy, gros TTS GPU (VoiceDesign 1.7B), world model local — hors profil SKU10, aucun dépannage prévu pour eux ce soir.
